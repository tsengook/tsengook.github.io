# Apple Tense Arena · 信息架构与页面线框（V1）

## 1. 产品目标
- 用户在“扮演苹果”与“操控时态”两种视角中理解 12 个英语时态。
- 每次时态触发都绑定微测验，保证学习闭环。
- 支持一局结束后的诊断反馈与复盘。
- 强化“反复掉下来→弹回去→再掉下来”的黑色幽默循环，形成强记忆点。

## 1.1 核心搞笑机制（Bounce Torture Loop）
- 每个回合默认包含三个阶段：`Drop`（掉落）→ `Bounce`（弹回）→ `Drop Again`（二次掉落）。
- 玩家在苹果视角会经历“刚以为结束，结果又被拉回空中再摔一次”的反转。
- 该循环与时态绑定：
  - **Simple**：单次掉落（节奏干脆）。
  - **Continuous**：持续上下弹跳（掉下来上去掉下来上去）。
  - **Perfect**：直接结算“已经被摔过”的结果状态。
  - **Perfect Continuous**：显示“已经连续被摔了多久”。

## 2. 站点结构（Sitemap）
1. `/` 首页
2. `/onboarding` 新手引导
3. `/battle` 对战主界面
4. `/result` 结算与诊断
5. `/review` 错题复盘
6. `/library` 时态知识库
7. `/profile` 个人数据（可选）

## 3. 页面线框说明

### 3.1 首页 `/`
**区块**
- Hero：一句话钩子（“你是一颗被时态支配的苹果”）
- 模式卡片：Apple Mode / Controller Mode
- 时态预览：12 张技能卡横向滚动
- CTA：开始挑战

**关键交互**
- 点击模式卡片切换默认玩法
- 点击“开始挑战”进入 onboarding 或 battle

### 3.2 新手引导 `/onboarding`
**区块**
- 角色设定：苹果状态条介绍（Freshness / Bruise / Pressure）
- 时间轴说明：Past / Present / Future
- 四类时态说明：Simple / Continuous / Perfect / Perfect Continuous
- 三问法提示：何时发生？是否进行中？是否强调结果或时长？

**关键交互**
- 3 步引导，可跳过
- 完成后写入 `tutorial_completed=true`

### 3.3 对战页 `/battle`
**布局（左右结构）**
- 左侧：苹果舞台（动画、受击、状态）
- 右侧：时态控制台（12 技能卡、能量槽、连击）
- 底部：题目弹窗区（多选/排序/改错）
- 顶部：回合信息（回合计时、当前关卡）
- 中央叠层：循环轨道（可视化 Drop/Bounce/Drop Again）

**关键交互**
- 选择时态卡 -> 弹出题目 -> 答对触发技能动画
- 答错触发“轻惩罚 + 解释弹层”
- 支持暂停、重开、静音
- 连续答对可触发“无限弹跳 3 秒”搞笑奖励镜头（无额外惩罚，仅增强记忆）

### 3.4 结算页 `/result`
**区块**
- 生存结果：苹果最终状态 + 总分
- 时态准确率雷达图
- 错误分布：易混时态对（如 PP vs PPC）
- 下一步建议：进入复盘 / 再来一局

### 3.5 复盘页 `/review`
**区块**
- 错题列表（按时态聚类）
- 每题解释（时间轴 + 结构模板 + 例句）
- 一键再测（仅错题）

### 3.6 知识库 `/library`
**区块**
- 12 时态卡片墙
- 每卡包含：结构、时间线、常见错误、最小对比例句
- 搜索与筛选（按时间维度和难度）

## 4. 关键组件清单
- `AppleStage`：苹果状态与受击动画
- `TenseCardGrid`：12 技能卡
- `QuizModal`：题目弹窗
- `TimelineStrip`：过去-现在-将来时间轴
- `ResultRadarChart`：时态准确率图表
- `MistakePairCard`：易混时态对比卡
- `BounceLoopTrack`：掉落/弹回/再掉落的节奏轨道组件

## 5. 最小可交付页面优先级
P0（首发必须）
- `/` `/battle` `/result`

P1（第二阶段）
- `/onboarding` `/review`

P2（扩展）
- `/library` `/profile`
