# Apple Tense Arena · 综合增强方案（网站 + 动态内容 + 小程序）

## 1. 综合体验蓝图
将现有三份文档整合为统一交付链路：
1. **教学叙事层**：12 时态通过苹果受控命运来记忆。
2. **玩法系统层**：Bounce Torture Loop 作为持续笑点与记忆锚。
3. **产品分发层**：Web 主站 + 短视频切片 + 微信小程序轻入口。

## 2. 内容结构增强（可直接给内容团队）

### 2.1 三段式关卡节奏
- **Act A（认知冲击）**：掉下来上去掉下来上去，强调“进行态”。
- **Act B（规则理解）**：通过题目解释“完成态 vs 完成进行态”。
- **Act C（迁移应用）**：让用户用目标时态写一句“苹果自述”。

### 2.2 单关卡脚本模板
- 开场旁白：`You are not falling once. You are falling in grammar.`
- 回合循环：
  - 触发时态技能
  - 回答题目
  - 播放掉落/反弹镜头
  - 弹出一句语法解释
- 结尾总结：给出本回合最易混淆时态对比。

### 2.3 互动内容矩阵
- **学习输入**：时态卡、时间轴、短解释。
- **行为输出**：选句、改错、排序、造句。
- **结果反馈**：准确率、连击、最容易错的时态对。

## 3. 分端实现建议

### 3.1 Web（主产品）
- 负责完整动画、长流程学习和复盘。
- 支持导出回放数据（供短视频和小程序复用）。

### 3.2 动态视频（传播）
- 从一局数据自动生成 30~60 秒切片。
- 模板段落：反复掉落名场面 + 时态讲解金句 + CTA。

### 3.3 微信小程序（轻量学习入口）
- 定位：碎片化练习，1-3 分钟一局。
- 保留核心：时态题 + 掉落反弹动画 + 即时讲解。
- 裁剪复杂特效，保证低端机流畅。

## 4. 小程序页面规划
1. `pages/home/index`：模式选择、开始挑战。
2. `pages/battle/index`：题目 + 苹果舞台 + 技能按钮。
3. `pages/result/index`：本局得分、错误分析。
4. `pages/review/index`：错题再练。

## 5. 小程序 API 对接契约（可复用 Web）
- `GET /api/tenses`
- `GET /api/quiz?tenseId=...`
- `POST /api/battle/submit`
- `GET /api/result/:runId`

## 6. 执行顺序（推荐）
- 第 1 步：先完成小程序静态页面与题目流程。
- 第 2 步：接入循环动画参数（drop/bounce/dropAgain）。
- 第 3 步：接入后端统计并打通结果页。
- 第 4 步：同步 Web 与小程序词库/题库。
